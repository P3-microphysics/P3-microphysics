# Test Summary – v5.6.3 (Seifert and Beheng 2001 autoconversion constant)

**Date:** 2026-10-23
**Change:** `5aa3ee1` (Hugh Morrison, branch `bugfix-sbaut`), merged into `dev` as `4f993bd`, which also sets
both version markers to 5.6.3. The same change is merged into `dev-aerosols` as 6.0.0-rc4 (`8ce169d`, from
`7fd4eb4` on `dev-aerosols-sbaut`).
**Prepared by:** Jason Milbrandt, with Claude Code
**Scope:** kin1d regression suite (Tier 1) on two machines, kin1d and WRF with SB2001 switched on (recorded in the
fix commit), and an independent evaluation of the rate. No GEM/HRDPS run (Gate C not run; version untagged).

---

## Summary

With `autoAccr_param = 1` (Seifert and Beheng 2001, SB2001), the cloud-to-rain autoconversion rate was computed as

    qcaut = kc*1.9230769e-5*(nu+2)*(nu+4)/(nu+1)**2 * (rho*qc*1e-3)**4/(rho*nc*1e-6)**2 * (1 + ...) * 1000/rho

The constant is 1/(20 x*), with x* = 2.6e-7 g the drop mass separating cloud and rain. The expression is evaluated
in cgs units, like `kc` (9.44e+9 cm³ g⁻² s⁻¹) and the qc and nc terms (g cm⁻³, cm⁻³), so the constant is
1.9230769e+5. The rate was therefore 10¹⁰ too small, and SB2001 produced almost no warm rain. The number tendency
`ncautc = qcaut*7.6923076e+9` (2/x*) was already correct. v5.6.3 corrects the constant and adds a comment giving
its derivation.

The error is present in every P3 version checked (3.1.6 to 6.0.0-rc3). It affects only `autoAccr_param = 1`; the
default is 2 (Khairoutdinov and Kogan 2000, KK2000), so default configurations are unchanged.

**Result: PASS.** The default configuration is bit-identical; with SB2001 on, warm rain is restored and close to
KK2000 in kin1d.

## 1. Rate check

For qc = 1 g/kg, Nc = 100 cm⁻³, ν = 1, τ = 0, ρ = 1 kg m⁻³:

| Evaluation | Autoconversion rate (kg kg⁻¹ s⁻¹) |
|---|---|
| SB2001 evaluated directly in SI units (kc = 9.44e9 m³ kg⁻² s⁻¹, x* = 2.6e-10 kg) | 6.81e-10 |
| P3 expression, constant 1.9230769e+5 (v5.6.3) | 6.81e-10 |
| P3 expression, constant 1.9230769e-5 (v5.6.2 and earlier) | 6.81e-20 |

Hugh Morrison obtained the same values; they were recomputed independently for this summary. The box model ported
from P3 (arthurzqhu/box-model-sdm) already uses e+5.

## 4. WRF (Hugh Morrison)

WRF 4.8.0 `em_quarter_ss` supercell, `mp_physics = 51`, Δx = 1 km, 100 km domain, 60 min. SB2001 forced on as in
§3; old constant, fixed constant, and KK2000 (unmodified v5.6.2). At 30 min:

| | KK2000 | SB2001 old | SB2001 fixed |
|---|---|---|---|
| qr in ice-free columns, sum (kg/kg) | 0.042 | 0.0003 | 0.013 |
| qr in ice-free columns, max (g/kg) | 4.3 | 0.02 | 1.3 |
| qr below 0 °C, sum (kg/kg) | 2.10 | 0.45 | 0.97 |
| qc total, sum (kg/kg) | 1.89 | 4.57 | 2.58 |
| Max surface precipitation (mm) | 12.2 | 2.0 | 3.1 |

With the old constant warm rain is essentially absent and cloud water accumulates; the fix restores it, with a
slower onset than KK2000. At 60 min the domain-mean surface precipitation is similar for the old and fixed constant
(0.37 vs 0.36 mm; KK2000 0.52 mm), because in the supercell rain forms mainly through melting rimed ice. Rain
totals in deep convection therefore do not reveal the error.
