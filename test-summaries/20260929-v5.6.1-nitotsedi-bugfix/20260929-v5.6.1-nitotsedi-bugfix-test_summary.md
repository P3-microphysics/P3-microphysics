# Test Summary – v5.6.1 (BUG-007: ice sedimentation `nitot` gate)

**Date:** 2026-09-29
**Change:** `48a544d` (Hugh Morrison, branch `bugfix-nitotcheck-sed`), merged into `dev`
as `0c87e1b`, which also sets both version markers to 5.6.1.
**Prepared by:** Jason Milbrandt, with Claude Code
**Scope:** kin1d regression suite (Tier 1) plus host-model evidence from WRF and CM1
recorded in the fix commit. No GEM/HRDPS run (Gate C not run; version untagged).

---

## Summary

v5.6.0 contained a regression introduced by `4dd2cc9` (2026-06-23): the consolidated
`sedimentation_ice` routine computed lookup-table fall speeds only when
`qit >= qsmall` **and** `nit >= nsmall`. Where ice mass was present with number below
`nsmall` (normally `nit < 0` on entry, left by the process-rate updates), `V_qit` and
`V_nit` stayed 0 and the ice did not sediment. The held mass accumulated and produced
isolated spurious reflectivities of 98–111 dBZ in host models. The `nit >= nsmall`
condition protected nothing, since `nit` is already floored at `nsmall` before the
lookup-table call. v5.6.1 removes that condition; the `qil < qit` guard (BUG-001)
is unchanged.

**Result: PASS.** kin1d changes only at trace ice in the two configurations where the
gate fires; WRF shows the outliers removed and maximum reflectivity back at the
v5.5.2 level.

### 1.3 Version-string change

The version-marker change (`5.6.0+nitotsedi` → `5.6.1`, part of `0c87e1b`) was
checked by running the suite on the merged tree before and after the marker edit:
all six configurations bit-identical.

### 1.3 Coverage note

kin1d never produces g/kg ice with collapsed number, so it detects the change but
cannot reproduce the symptom. The host-model evidence below carries that.

## 3. CM1 (gate census)

`quarter_ss`, Δx = 1 km, 60 min, P3 1-category 3-moment + liquid fraction,
`5.6.0+qwgrth` with the gate instrumented: 2750 gate events; 98 % with `nit < 0` on
entry, 99.5 % at the first sedimentation substep, 90 % below 1e-9 kg/kg, 32 events with
`qit ≥ 1e-6 kg/kg`, largest 4.4 g/kg (`nit = −1353 kg⁻¹`), mostly at k = 10–14. The
`qil >= qit` guard never fired.
